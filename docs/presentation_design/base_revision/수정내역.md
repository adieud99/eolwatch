# 베이스 PPT 반영 수정

- 대상: 직전 시스원활용제안 복사본
- 1·3페이지: 슬라이드 XML과 이미지 연결 정보를 바이트 단위로 그대로 보존
- 2페이지: ppt베이스4.pptx 3장 직접 복사. 시스원 업무 활용, 프로젝트 역할, 취약점·지원 종료·조치 보고의 세 항목으로 문구 교체
- 4페이지: ppt베이스4.pptx 4장 직접 복사. 원본 녹색/회색 패널·아이콘·구분선을 유지하고 제공 결과물과 적용 전 확인사항으로 문구 교체
- 20×11.25인치 베이스 개체·글꼴을 현재 슬라이드 크기 13⅓×7.5인치에 맞춰 전체 2/3 등비 축소
- 원본 색상과 210 옴니고딕·JASO Sans·JASO Sans Bold 서체 유지
- 원본 베이스/기존 요약서 파일 변경 없음. 외부 관계 링크 및 패키지 무결성, 변경 페이지 본문 폭, 육안 미리보기 점검 완료

미리보기는 PPT 도형과 글꼴을 별도로 그린 구성 검토용입니다. 제목은 macOS CoreText로 원본 210 옴니고딕을 렌더링했습니다. PowerPoint의 PDF 내보내기는 AppleEvent 시간 초과로 완료되지 않아 PDF를 제공하지 않았습니다.
