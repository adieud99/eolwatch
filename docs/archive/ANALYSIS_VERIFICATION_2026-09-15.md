## 실행 아티팩트

Git에서 제외되는 다음 경로에 실제 원본과 실행 기록이 있다.

- 분석 실행: `infrastructure/local-vm/runtime/analyses/20260915T085139Z-LAB-VM-01-d7a2dd1e/`
- 저장 실행: `infrastructure/local-vm/runtime/analyses/20260915T085521Z-LAB-VM-01-066ba743/`

분석 실행 폴더에는 Syft JSON, SPDX JSON, Grype JSON, 가져오기 묶음, 도구 버전·바이너리 및 입력 파일 해시, 명령·종료 코드·경고를 담은 manifest가 있다. 저장 실행은 원본 파일 해시를 확인해 재수집 없이 업로드하고 결과를 기록했다.

처음 도구 옵션을 맞추는 과정의 실패 실행도 별도 폴더의 manifest에 남겼다. `.yaml` 설정 파일과 `./proc/**` 등의 올바른 제외 패턴으로 보완한 뒤 성공한 실행을 위에 명시했다.

## 검증 및 보완

- 백엔드 테스트 22개 통과. 원본 보존, 중복 방지, 잘못된 보고서 전체 롤백, 명시적 0건과 필드 누락 구분, 조회자 권한, CVE 별칭·다중 수정 버전, 파일 소유관계 보존과 패키지 그래프 분리 포함.
- 프런트엔드 테스트 7개 및 프로덕션 빌드 통과. 업로드, 선택 SBOM별 결과, 조회자 권한, 100행 페이지 이동 포함.
- 실제 Chrome에서 로그인 → CVE 조치 → 분석 #1 선택 → 100행 표시·페이지 이동·SBOM 필터 해제 및 복원 확인. JavaScript 실행 오류 및 API HTTP 오류 0건. 도구 버전·DB 날짜·LAB-VM-01 연결 표시를 확인했으며 증빙 화면은 `reports/analysis-tools.png`에 저장했다.
- 임시 SQLite의 upgrade → 모델 검사 → downgrade → upgrade 통과.
- 맥 Docker·controller VM PostgreSQL 모두 revision `c4d62a8170b3`, 모델과 차이 없음.
- 두 로컬 서비스에 API·화면·Nginx 설정을 반영했으며 `/health` 정상.
- 실제 목록 조회에서 큰 원본을 불러오지 않도록 개선. 한 번의 측정에서 분석 이력 조회는 0.01초 미만, 12,241건 CVE 조회는 약 0.41초였다. 정식 부하 시험 수치가 아니다.
- 원본 보고서에는 Grype의 `ignoredMatches`도 보존한다. 화면 건수는 `matches`에서 구성요소에 연결한 CVE를 기준으로 한다.

## 현재 접속 및 다음 단계

<http://127.0.0.1:18080>에 로그인해 `CVE 조치` → 분석 #1의 `CVE 보기`를 누르면 실제 결과를 확인할 수 있다. 맥 Docker도 같은 소스로 갱신했지만 분석 데이터는 별도 DB인 VM 서비스에 저장했다.

현재 단계는 분석 도구 연결과 결과 저장·조회까지다. 이후 진행할 일은 다음과 같다.

1. 실제 배포판·소스 패키지·실행 커널 기준의 영향 판단 검증

3. 업데이트 전후 SBOM·재분석 비교와 조치 완료 판단
4. 검증된 결과에 맞춘 최종 제출 자료 정리
